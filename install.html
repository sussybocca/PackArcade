Arcade Web App

Version 2.0.0
Install Arcade Web App as a real application on your device. Get native-like experience with offline support and enhanced features.

📱 How to install on iOS:

  1. Tap the Share button ⬆️ in Safari
  2. Scroll down and tap Add to Home Screen
  3. Tap Add in the top right corner
  4. The app will appear on your home screen!

📱 How to install on Android:

  1. Tap the menu button (⋮) in Chrome
  2. Tap Install App or Add to Home screen
  3. Tap Install to confirm
  4. The app will be installed on your device!
